# FPN-68

This repository is a EuroScope plugin that simulates an FPN-68 style precision approach radar, for use in military control on VATSIM.

## Installation instructions

- Download the `.dll` file from the latest release
- Put it in your EuroScope plugins folder
- Load, and **make sure** "Standard ES Radar Screen" is in the "Allowed to draw on types" column.
